# Checklist de evidencias (capturas de pantalla)

1. **Repositorio creado**: vista principal del repo en GitHub con `README.md`.
2. **Colaborador invitado**: sección *Settings → Collaborators* mostrando invitación pendiente/aceptada.
3. **Rama de funcionalidad**: lista de branches con `feature/flight-search`.
4. **Commits convencionales**: historial mostrando mensajes `feat(flights): ...` y `test: ...`.
5. **Pull Request abierto**: pantalla del PR con descripción y referencia al Issue (ej.: `Closes #1`).
6. **Comentarios de revisión**: conversación del PR con sugerencias/resoluciones.
7. **Checks de CI**: sección *Checks* del PR en verde.
8. **Issue de integración hoteles**: issue con etiquetas `integration` y `regulatory`.
9. **CODEOWNERS activo**: tooltip/solicitud automática de revisión a propietarios.
10. **Reglas de protección de rama**: *Settings → Branches* mostrando regla para `main`.
