# Guion de video (Actividad 4)

**Objetivo:** demostrar colaboración en GitHub con ramas, PR, Issues y buenas prácticas.

1. Intro (10–15s): contexto del proyecto y objetivos.
2. Crear repo y añadir colaborador (Settings → Collaborators).
3. Crear rama `feature/flight-search` y hacer commits convencionales.
4. Abrir PR, explicar plantilla, vincular a Issue y solicitar revisión.
5. Mostrar comentarios, resolución de conflictos y checks de CI.
6. Crear Issue para integración de hoteles (plantilla + etiquetas).
7. Explicar `CODEOWNERS` y protección de `main`.
8. Cierre: resumen de buenas prácticas aplicadas y próximos pasos.
