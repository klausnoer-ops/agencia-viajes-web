# Contribuir

## Ramificación
Usamos **GitHub Flow**: ramas cortas descriptivas desde `main` (ej.: `feature/flight-search`).

## Convención de commits
Adoptamos **Conventional Commits**:
- `feat(scope): descripción` nueva funcionalidad
- `fix(scope): descripción` corrección
- Tipos adicionales: `docs`, `test`, `ci`, `build`, `refactor`, `chore`, etc.

## Pull Requests
- Plantilla obligatoria con contexto y capturas si aplica.
- Vincular a Issues (palabras clave: `Closes #ID`).
- Al menos **1 aprobación** y checks de CI verdes.

## Issues y discusiones
- Usar etiquetas: `bug`, `enhancement`, `integration`, `ux`, `regulatory`.
- Dividir tareas grandes en sub-issues.
